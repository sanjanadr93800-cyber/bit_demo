# ChromaGrid – Beautiful Image Gallery

## 📌 Project Description

ChromaGrid is a modern and interactive image gallery developed using React.js. It displays a collection of beautiful photographs in an attractive grid layout with creative titles, subtitles, and colorful visual effects.

The gallery includes different categories such as cats, beaches, nature, birds, fashion, and sunsets. It provides a visually appealing way to explore and enjoy different photographs.

## ✨ Features

- Interactive ChromaGrid layout.
- Beautiful image gallery.
- Multiple image categories.
- Creative image titles and subtitles.
- Attractive colors and visual effects.
- Modern and clean user interface.
- Easy to customize images and content.
- Responsive design.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## 🚀 Installation and Setup

**Step 1: Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

**Step 2: Open the project folder**

```bash
cd bit_demo
```

**Step 3: Install dependencies**

```bash
npm install
```

**Step 4: Start the development server**

```bash
npm run dev
```

**Step 5: Open the application**

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
